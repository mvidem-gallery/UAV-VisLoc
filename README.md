# UAV-VisLoc
This project estimates UAV geopositioning using only an aerial photo from a drone and a large satellite map. The core idea is to extract keypoints (SuperPoint) from both the drone image and map chunks, then perform keypoint matching (LightGlue) to identify acceptable map areas. If a match is found, a homography matrix is computed using MAGSAC to determine the exact coordinates where the photo was taken. To optimize the pipeline, keypoint operations are restricted to the top 20 most reliable map tiles, selected by comparing FP16 embeddings generated by the pretrained DINOv2-giant model.
